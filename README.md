# prime-mind-chatbot
Here’s a simple, general description (under 350 characters):  PrimeMind Chatbot is an interactive Streamlit app that lets users chat with an AI assistant. It generates responses in real time, remembers past messages, and displays answers with a human-like typing effect for a smoother, more natural conversation experience.

## 🚀 Features

### **✨ Unique Response Variation**
- High temperature and top-p settings for creative wording.  
- Hidden “variation key” ensures fresh phrasing each time.  
- System prompt enforces tone shifts and vocabulary diversity.

### **💬 Real-Time Chat Interface**
- Clean Streamlit chat layout.  
- Persistent chat history with user/assistant message rendering.

### **⌨️ Human-Like Typing Effect**
- Streams responses character-by-character for realism.

### **⚡ Powered by Groq**
- Uses `llama-3.3-70B-versatile` for fast, low-latency responses.

### **🔐 Secure Configuration**
- Loads environment variables with `python-dotenv`.
